# Trinetra Consultancy

A complete four-page static website, built locally with HTML, CSS and JavaScript. This is the selected final design, positioned as **AI-enabled Business Consultancy**, with the supplied Trinetra logo, a single AI-focused illustration, locally stored Manrope and Inter fonts, and responsive layouts. The former Data / Judgment / AI pillars have been removed. There is no application server, database, runtime package dependency or Sites integration.

## Open the website

Double-click `index.html` to open the website directly in your browser. All four pages, navigation, accordions and email links work when opened this way.

For a local HTTP preview, run this command from this folder:

```powershell
npm.cmd start
```

Then visit <http://127.0.0.1:4173>. The server binds only to your computer. To stop a server started in a terminal, press Ctrl+C.

## Pages and files

Keep visible website text at **14px or larger**, including section labels, captions, navigation, buttons and footer text, on both desktop and mobile. Small text uses the shared `--text-small: 14px` CSS variable. Do not reintroduce smaller labels in future changes.

- `index.html` — Home
- `services.html` — all six service packages and deliverables
- `about.html` — the name, mission and four founders
- `contact.html` — contact details, LinkedIn, a direct-submit enquiry form and five FAQ accordions
- `assets/styles.css` — responsive design, local fonts and animation
- `assets/main.js` — mobile navigation, enquiry submissions, scroll reveals and animation controls
- `assets/images/trinetra-logo.jpeg` — latest supplied logo, saved unchanged
- `assets/favicon.svg` — browser-tab icon displaying the supplied logo's triangle
- `site.config.json` — editable contact details, services, founders and FAQs
- `scripts/build.mjs` — generates the four HTML pages using the shared header/footer

The HTML files are already built and included. Visitors do not need Node.js or npm.

GitHub Pages publishes the root of the `main` branch. To update the website, run `npm.cmd run build` and `npm.cmd run check`, then commit and push to `main` using the account above.

All page and asset links are relative, so the same files can run at either an account Pages address or a repository Pages subpath. The `.nojekyll` marker is included. The generated root HTML files and the `assets` directory are the deployable website; no build step is required by the host.

Keep `node_modules`, `preview`, and local logs out of Git. They are already excluded in `.gitignore`. Font license files should accompany the bundled fonts. No domain-dependent canonical URLs or sitemap have been invented; those can be added after the final public URL is known.

## Verification

Development-only browser checks use Playwright and axe-core. They are not shipped to visitors.

```powershell
npm.cmd ci
npx.cmd playwright install chromium
npm.cmd run check
```

The checks cover four page widths (320, 390, 768 and 1440 pixels), horizontal overflow, local assets, keyboard navigation, accordions, reduced motion, quote subjects and bodies, links under a repository subpath, and fallback behavior without JavaScript. Automated WCAG A/AA scans run at desktop and phone sizes; they are a useful check rather than a certification of accessibility.

Screenshots and the verification report are saved under `preview/`. This directory is for local review only and is excluded from Git.
